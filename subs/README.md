# Supporting Topics

This directory contains supporting aviation topics for **Flight Level Zero** that are not specific to one aircraft.

Possible subjects include aerodynamics, weather, navigation, aircraft systems, airport operations, flight simulation, and other foundational concepts as they are developed in the project.

## Suggested File Format

- What is it?
- Why does it matter?
- How does it work?
- Beginner questions
- Vocabulary
- Sources

Only create topic files when the material actually exists in the project.
