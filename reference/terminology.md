# Terminology Standards

> **Status:** Active development

This file tracks preferred terminology used throughout **Flight Level Zero** so technical terms remain consistent.

## General Rules

- Define specialized aviation terminology when it first appears.
- Prefer the technically correct term when a simpler substitute would be misleading.
- Use the same term consistently for the same concept.
- Distinguish between broad and specific terms when the distinction matters.
- Record terminology decisions here when a term could reasonably be written more than one way.
