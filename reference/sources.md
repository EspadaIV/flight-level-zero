# Sources

> **Status:** Active development

This file tracks sources used to research and verify technical material in **Flight Level Zero**.

## Source Standards

Whenever possible, prioritize:

1. Government aviation and aerospace agencies
2. Aircraft manufacturers
3. Museums and archival institutions
4. Universities and established educational organizations
5. Reputable aviation publications

Avoid treating unsourced summaries, social media posts, or AI-generated text as authoritative technical sources.
